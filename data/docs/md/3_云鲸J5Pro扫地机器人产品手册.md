# 云鲸J5 Pro 家用扫地机器人产品手册
> 电商平台商家知识库文档，用于商品咨询、客服问答、RAG检索

## 1. 产品概述
云鲸J5 Pro是旗舰款自动集尘+自动洗拖布一体扫地机器人，支持全屋导航、AI物体避障、多楼层地图记忆，可实现自动清扫、自动回洗拖布、自动集尘、热风烘干拖布。本文档包含清扫模式、避障参数、耗材更换周期、保修政策、电商平台7天无理由退换条件。

## 3. 清扫模式
1. **自动全屋清扫**：默认模式，扫描全屋地图，分区依次清扫，遇到脏污区域自动复扫；完成后自动回基站清洗拖布、集尘。
2. **分区清扫**：APP手动选定房间/区域单独清扫，支持设置每个房间清扫次数、拖地水量。
3. **定点清扫**：针对局部重污区域，以点位为中心1.5m范围，重复清扫2次+拖地。
4. **仅扫地**：只吸尘，不拖地，适合短毛地毯、干燥浮尘场景。
5. **仅拖地**：关闭吸尘，只执行拖地，适合日常地面轻度污渍。
6. **沿边清扫**：紧贴墙角、家具边缘清扫，弥补主刷盲区。
7. **勿扰模式**：22:00–次日8:00自动降低噪音，不启动清扫。

## 4. 避障参数与识别能力
- 避障响应距离：前方10–60cm提前识别障碍物并减速绕行。
- 可识别物体：拖鞋、数据线、袜子、宠物粪便、水杯、鞋子、体重秤、宠物碗。
- 识别限制：黑色超细线缆、超薄地毯边缘、高度低于2cm扁平物体识别概率下降；镜面、高反光物体容易误判。
- 最大翻越高度：20mm门槛（大于2cm门槛无法翻越，需要安装虚拟墙）。
- 跌落防护：底部4组红外防跌落传感器，楼梯边缘自动停止后退。

## 5. 耗材更换周期（日常家庭，每日清扫1次参考）
1. **滚刷（主地刷）**：6个月更换一次；毛发缠绕严重可提前更换。
2. **边刷（侧刷）**：3个月更换一次，磨损、掉毛即更换。
3. **HEPA滤网**：3个月更换；潮湿环境建议2个月，不可水洗（水洗会破坏过滤层）。
4. **拖布**：2–3个月更换；出现起球、发硬、清洗不掉污渍时更换。
5. **集尘袋**：自动集尘基站，**30天更换一袋**，家庭灰尘多可缩短至20天。
6. **基站污水/清水箱密封圈**：12个月检查，老化漏水则更换。

> 提示：耗材属于消耗品，不在官方保修范围内。

## 6. 官方保修政策（国行正品）
1. **保修期限**：主机整机1年保修；基站1年保修。耗材不在保修。
2. 保修起算时间：平台订单签收日期。
3. ✅ 免费保修：非人为硬件故障（雷达故障、电池故障、电机故障、主板故障）。
4. ❌ 不保修场景
    - 进水、液体浸泡、基站长期积水发霉造成损坏
    - 人为撞击、跌落造成雷达、外壳碎裂
    - 私自拆机、第三方改装维修
    - 耗材自然磨损、毛发堵塞未及时清理造成的电机烧毁
    - 宠物粪便、异物进入机器内部造成腐蚀损坏

## 7. 电商平台7天无理由退货条件（平台规则）
> 时效：签收当日起7天内提交申请，**全部条件必须同时满足**
1. 主机、基站外观无磕碰、裂纹、划痕，无进水、污渍、宠物粪便污染。
2. 全套配件齐全：主机、基站、电源线、备用边刷、备用滤网、说明书、外包装箱完整。
3. 机器仅试运转，无大量长时间清扫造成的严重脏污，滚刷、拖布无重度毛发缠绕。
4. 非定制工程机、非特供版本。

### ❌ 直接驳回7天无理由申请场景
- 机器内部残留大量灰尘、宠物粪便、顽固污渍无法清理
- 外壳磕碰、雷达盖板碎裂、进水痕迹
- 配件丢失、外包装箱丢失或严重破损
- 超过签收7天申请时效

> 运费说明：满足7天无理由退货场景，退货运费由买家承担；订单如有运费险，可抵扣首重运费。

## 8. 质量问题售后规则
签收15天内，经品牌官方检测确认存在原厂硬件质量故障，可申请换货；人为损坏不在质量售后。

## 9. 使用注意事项
1. 清扫前请提前收好地面数据线、袜子、小杂物，降低卡机风险。
2. 高度＞2cm门槛无法翻越，需要在APP设置虚拟墙。
3. 不要在潮湿积水地面使用，防止机器进水。
4. 每次清扫结束建议定期清理基站污水箱，防止异味滋生。
