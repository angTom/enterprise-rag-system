# 森海塞尔 MOMENTUM True Wireless 5 旗舰真无线耳机 产品手册

## 1. 产品概述
森海塞尔MOMENTUM True Wireless 5为品牌最新旗舰真无线入耳耳机，搭载**混合自适应主动降噪**，支持高清无损音频、AI通话降噪，适配iOS/Android双平台，支持森海塞尔Smart Control Plus APP自定义音效。本手册包含硬件参数、降噪等级、续航、配对教程、官方保修、电商平台7天无理由退换条件。

## 3. 降噪等级与模式
**混合自适应ANC主动降噪**，实时采集环境噪音自动调节降噪强度，支持3档手动调节：
1. **强降噪模式**：适合地铁、飞机、公路等低频嘈杂环境，最大抑制深度42dB；
2. **轻度降噪**：办公室、咖啡馆，保留少量环境音，降低耳压；
3. **通透模式（透明聆听）**：放大外界人声，无需摘下耳机与人对话。

> 降噪可在耳机触控或者Smart Control Plus APP内切换，APP还支持自定义降噪曲线。

## 4. 续航时长（中等音量，实验室标准测试）
1. 耳机单耳：
    - 开启ANC降噪：连续6小时
    - 关闭ANC降噪：连续12小时
2. 搭配充电盒总续航：**40小时（降噪开启）**
3. 快充：充电8分钟，可连续播放1小时；充满整机约1.5小时
4. 充电盒支持USB‑C有线充电 + Qi无线充电。

## 5. 配对教程
### 首次配对
1. 打开充电盒，耳机保持在盒内；
2. 保持充电盒开盖状态，长按充电盒侧面功能键3秒，指示灯蓝白交替闪烁，进入蓝牙配对模式；
3. 手机打开蓝牙，搜索设备名称 `Sennheiser MTW5`，点击连接；
4. 连接成功后指示灯变为常亮，可打开Smart Control Plus APP完成固件升级与音效个性化设置。

### 重新配对 / 重置耳机（配对失败时）
1. 将耳机放入充电盒，保持开盖；
2. 长按充电盒功能键10秒，指示灯红+蓝快速闪烁，完成设备重置；
3. 手机端删除旧的蓝牙配对记录，再重复首次配对流程。

### 多设备切换
耳机支持双设备同时连接，在APP内开启多设备联动，播放时自动切换音源。

## 6. 官方保修政策（国行正品）
1. **保修期限**：整机（耳机+充电盒）**12个月有限保修**，自购买签收之日起计算，仅面向第一手购买用户。
2. ✅ 免费保修范围
    - 非人为产生的硬件故障：耳机无声、充电异常、麦克风失效、主板故障，无进水、无磕碰损坏。
3. ❌ 不在免费保修，需付费维修
    - 耳机进水、液体腐蚀、大量汗水长期侵蚀
    - 外力跌落、挤压、外壳碎裂
    - 私自拆机、第三方维修、改装
    - 耳套、耳塞等消耗品（硅胶耳套不属于保修范围）
    - 电池自然老化衰减（12个月保修期内电池严重衰减可检测保修；超出保修期电池更换收费）
4. 保修渠道：森海塞尔授权服务中心，申请保修需要订单购买凭证。

## 9. 使用注意事项
1. IP54仅防泼溅，禁止游泳、洗澡、桑拿佩戴，进水损坏不在保修；
2. 长期大量出汗后建议及时清理耳机出声网，防止堵塞、腐蚀；
3. 不要使用非正规快充头，避免充电盒损坏；
4. 可在APP内升级固件，优化降噪、音质与通话效果。
